# Artemis vs UFOs (pygame-ce)

A horizontal spaceship shooter: your Artemis-style NASA ship on the left,
green-alien UFOs coming from the right.

## Setup
1. Make sure Python 3 is installed.
2. Open a terminal in this folder and run:
   ```
   pip3 install pygame-ce
   ```

## Play
```
python3 galaga_vertical_backup.py
```

## Controls
- Up/Down or W/S — move
- Space — shoot
- P — pause
- R — resume saved game
- Q / Esc — save and quit
- Enter — restart after game over

Your high score and saved game are stored next to the script
(`high_score.json`, `saved_game.json`).
